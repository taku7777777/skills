# モデル選択・委任の経済性のエビデンス

## 使い方

単価・倍率・製品挙動はすべて時点依存。成果物へ引用するときは確認日と出典URLを併記し、委任マトリクスの「見直し条件」に単価改定・モデル追加を明記する。SKILL.md には桁関係(単価比の桁感覚 1:3:5:10、Batch半額)だけを置き、具体額・倍率・製品挙動は本ファイルと一次URLを正とする。

## 一次情報

### 単価・課金構造(official)

- [Anthropic Pricing](https://platform.claude.com/docs/en/about-claude/pricing.md) — 2026-07-30参照、official。
  - $/MTok(入力/出力): Fable 5 $10/$50、Opus 5系 $5/$25、Sonnet 5 $2/$10(導入価格)、Sonnet 4.6 $3/$15、Haiku 4.5 $1/$5。
  - **Sonnet 5の導入価格は2026-08-31で終了**($2/$10 → $3/$15)。単価比の桁感覚(Haiku:Sonnet:Opus:Fable ≒ 1:3:5:10)はこの改定後の比。
  - Batch APIは入出力とも**50%割引**。キャッシュ倍率と乗算で重畳(例: Opus 5のBatch+cache readは $5×0.5×0.1 = $0.25/MTok)。ほとんどのバッチは1時間以内、最大24時間、結果保持29日。
  - 出力単価は入力の5倍(全モデル共通の桁関係)。thinkingトークンは出力単価で課金。
  - **Claude 4.7以降のモデル(Opus 4.7+・Sonnet 5・Fable 5等)は新トークナイザで同一テキストが約30%多くトークン化される**(Sonnet 4.6以前は旧トークナイザ)— 単価が同じでも実効コストが変わるため、モデル間の金額比較を単価だけで行わない。

### Claude Codeの製品挙動(official)

- [Claude Code: Manage costs effectively](https://code.claude.com/docs/en/costs) — 2026-07-30参照、official。
  - 「予想外の高額請求は、クリアされない長セッションか**Opusが既定のまま**に大抵帰着する」。
  - 公式指針: Sonnetが大半のコーディングをこなす。Opusは複雑なアーキテクチャ判断・多段推論に温存。
  - **agent teamsはplanモード時に標準セッションの約7倍のトークン**を消費。teammatesはSonnetへ、チームは小さく、済んだらshut down。
  - エンタープライズ実績: 平均約$13/開発者/稼働日、90%のユーザーは$30/日未満(予算の桁感覚)。
- [Claude Code: Sub-agents](https://code.claude.com/docs/en/sub-agents) — 2026-07-30参照、official。
  - サブエージェントのfrontmatter `model:` で haiku/sonnet/opus/fable/フルID/inherit を指定可能(既定 inherit)。安価モデルへのルーティングは公式ユースケース。
  - **v2.1.198以降、組み込みExploreサブエージェントはHaiku固定ではなくメイン会話のモデルを継承する。** 探索を安く保つには `model: haiku` のカスタムサブエージェントで明示上書きする — 「組み込みの既定は製品バージョンで変わる」の代表例。
- [Claude Code: Prompt caching behavior](https://code.claude.com/docs/en/prompt-caching) — 2026-07-30参照、official。
  - サブエージェントは独立コンテキスト・独自キャッシュで、**初回コールはキャッシュゼロから始まり、サブスクリプションでも5分TTL固定**(本体セッションは1時間)。forkは例外的に親キャッシュを読める。
  - キャッシュはモデル別。セッション途中のモデル切替はキャッシュ全損 — 切替はセッション冒頭か `/clear` 直後で。
- [Claude Code: Best practices](https://code.claude.com/docs/en/best-practices) — 2026-07-30参照、official。
  - headlessファンアウトは「**最初の2〜3ファイルで失敗からプロンプトを磨いてから全量に回す**」。
  - 調査・実装後の検証・アドバーサリアルレビューはフレッシュ文脈のサブエージェントへ(コンテキスト溢れ対策としての委任は公式推奨 — 委任自体は悪ではない)。

### 実測(industry-research)

- [metsuke](https://github.com/taku7777777/metsuke) — 2026-07-30参照、industry-research。単一ユーザー・34,000超リクエストの実測にもとづく行動変容システム。桁の参考であり普遍値ではない。
  - **最上位モデル(Fable 5)が総額の53%を占有** — 「モデル選択はコンテキスト整理やキャッシュ運用より大きな桁で効く」。
  - サブエージェント費の誤帰属はagent系コストの約1/4・総コストの約5%。spawn連鎖で指示へ因果帰属しないと高額指示のランキングが逆転する(時間帯の重なりによる帰属は誤る)。
  - **外部エージェント委譲(Codex等)は計測範囲の外へコストを逃がす。** 委譲先に規約ファイル(AGENTS.md)が無いと委譲のたびにリポジトリ探索が繰り返され、その費用は手元の台帳に現れない。
  - counter-metrics: **手戻り率・上位モデル差し戻し率**(原典の指標名。本スキルが「差し戻し率」と呼ぶのは後者に対応する)。「高品質タスクは高価でよい。『安くする』だけをKPIにしない」。

## 更新規律

- 四半期ごと、およびモデル追加・価格改定の発表時に再確認する。直近の既知の改定予定: **2026-08-31のSonnet 5導入価格終了**。
- 単価が変わっても「モデル構成比を最初に見る」「割当は検証手段とペア」「二重払いの検出」「counter-metricsとセット運用」という安定原則はSKILL.mdに残す。
- metsukeの実測値は単一ユーザー環境の値。自チームの構成比・単価分布は自前の計測(`llm-cost-observability`)で再測定してから割当を決める。
